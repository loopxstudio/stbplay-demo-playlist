# STBPlay Demo Playlist

A small M3U playlist for testing media players, including STBPlay. It contains links only. No video files are hosted in this repository.

## How to use

Add this playlist URL as an M3U source in your player:

https://raw.githubusercontent.com/loopxstudio/stbplay-demo-playlist/main/demo.m3u

No account, subscription or login is needed.

## What is in the playlist

Every entry is either an openly licensed film or a stream published by its owner specifically for testing video players.

### Official test streams

- Apple BipBop Advanced example stream - published by Apple for testing HTTP Live Streaming players.

The Big Buck Bunny, Tears of Steel and Sintel streams are hosted by Mux, Unified Streaming and Bitmovin respectively, as public demo streams for player testing. Those companies own and operate the hosting. Stream availability can change at any time.
